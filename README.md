# Cindermote

Portrait match-3 for iPhone and Android. Drag a piece into a neighbor to swap. Match three or more. Shuffle spends a level if the board stalls.

This is a mobile port of [luiz734/match3_game](https://github.com/luiz734/match3_game) (MIT). Artwork and audio are by luiz734, who stated those assets are free to use. Notices for the code, fonts, and the Godot Engine are in `THIRD_PARTY_LICENSES.md` and on the in-game Credits screen.

## Play

Open the project in Godot 4.7.2. The window is portrait. On a phone, drag a piece toward an adjacent one. The Menu button (or the Android back button) leaves a level. Credits lists third-party licenses.

## iOS (TestFlight)

Workflow: `.github/workflows/ios-testflight.yml` (`ios-testflight`).

It exports a Godot Xcode project on `macos-15`, archives it, signs with automatic cloud-managed signing (`xcodebuild -exportArchive`, `-allowProvisioningUpdates`, App Store Connect API key, method `app-store-connect`), and uploads with `altool`. The build number is `github.run_number`. `ITSAppUsesNonExemptEncryption` is false. If the bundle id is not registered yet, the workflow creates it with `POST /v1/bundleIds`.

Repo secrets (same ones the owner's other iOS workflow already uses):

- `APPSTORE_API_KEY_P8` — contents of the `.p8`, raw PEM or base64
- `APPSTORE_API_KEY_ID`
- `APPSTORE_API_ISSUER_ID`

The App Store Connect **app record** cannot be created by the API. If it does not exist, export and signing still run, then the upload step stops with an explicit error. Create it once in App Store Connect → Apps → + → New App:

- Name: Cindermote
- Bundle id: `es.verkvest.cindermote`
- SKU: `cindermote`

Then re-run the workflow.

## Android (Play)

Workflow: `.github/workflows/android-release.yml` (`android-release`).

`targetSdk` is **36** (required by Google Play for new apps and updates since 31 August 2026). `minSdk` is 24. The release job uploads an AAB and an APK when these secrets are set:

- `ANDROID_KEYSTORE_B64` — `base64 -w0 your-upload.keystore`
- `ANDROID_KEYSTORE_PASSWORD` — keystore password
- `ANDROID_KEY_ALIAS` — key alias

Godot's export preset has one password field and uses it for both the keystore and the key. Create the key with the same password, or set both passwords equal. `ANDROID_KEY_PASSWORD` is optional and must match `ANDROID_KEYSTORE_PASSWORD` if you set it.

Until those secrets exist, the workflow uploads a **debug-signed APK** artifact (`cindermote-debug-apk`) instead. That APK is for install checks, not for Play.

A separate job captures the main menu and a level at a 390×844 phone viewport and uploads them as `phone-screenshots`.

Icons are generated by `tools/generate_icons.py`.
